# LangPortal - Language Learning Portal
LangPortal is a language learning platform designed to help users improve their vocabulary through interactive activities and quizzes. The backend is built using Java and Spring Boot, while the frontend is developed with React and TypeScript.

## Features
***Backend***
 - ***Vocabulary Quiz Generation***: Uses OpenAI's GPT models to dynamically generate vocabulary quizzes based on the user's preferences (e.g., language and difficulty level).
- ***Study Activities***: Provides a list of interactive activities such as vocabulary quizzes, memory games, and word pairs.
- ***Database Integration***: Stores vocabulary data using SQLite for persistence.
- ***RESTful API***: Exposes endpoints for frontend integration.

***Frontend***

- ***Interactive UI***: Built with React and TypeScript, offering a user-friendly interface for accessing study activities.
- ***Dynamic Quiz Display***: Fetches and displays quizzes generated by the backend.
- ***Mock Data Support***: Includes mock data for testing the UI while the backend is under development.

## How to Run
***Backend***
1. Clone the repository: `git clone <repository-url>`
2. Navigate to the backend directory: `cd backend`
3. Install dependencies: `mvn clean install`
4. Run the application: `mvn spring-boot:run`
5. The backend will run on http://localhost:8081.

***Frontend***
1. Navigate to the frontend directory: `cd langportal/frontend-ts`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## API Endpoints
***Backend Endpoints***

1. Get Study Activities

    - URL: /api/study-activities
    - Method: GET
    - Description: Returns a list of available study activities.
2. Generate Vocabulary Quiz

    - URL: /api/study-activities/vocabulary-quiz
    - Method: GET
    - Description: Generates a vocabulary quiz using OpenAI's GPT models.
3. Import Vocabulary

    - URL: /api/vocab/import
    - Method: POST
    - Description: Imports vocabulary data from a specified source.
